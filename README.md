# juego-memoria

Juego de memoria con interfaz interactiva donde puedes elegir la dificultad y el tema. El juego permite guardar la partida y ofrece la opción de retomarla o empezar una nueva.

## Características

- Selección de dificultad (fácil, medio, difícil).
- Elección de diferentes temas visuales.
- Guardado automático de la partida.
- Opción para continuar una partida guardada o iniciar una nueva.
- Interfaz amigable y responsiva.

## Tecnologías utilizadas

- **PHP** (backend)
- **JavaScript** (frontend)
- **CSS/SCSS** (estilos)
- **Smarty** (plantillas)
- **HTML**

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/0HunterDreams1/juego-memoria.git

1. Configura tu entorno local con PHP y un servidor web (por ejemplo, XAMPP, WAMP o similar).
2. Coloca los archivos en la carpeta pública de tu servidor (por ejemplo, htdocs en XAMPP).
3. Accede al juego desde tu navegador en la ruta correspondiente (por ejemplo, http://localhost/juego-memoria).
### Uso
1. Ingresa al juego desde tu navegador.
2. Selecciona la dificultad y el tema que prefieras.
3. Juega, guarda tu partida y retómala cuando quieras.
